三步，连接你的设备。

请先准备好管理员提供的设备连接代码。

Windows 示例
01

安装 Tailscale 客户端

点击上方 Windows 下载按钮，运行安装包，按提示完成安装。

02

以管理员身份打开 CMD

在开始菜单搜索 cmd，选择“以管理员身份运行”。

03

粘贴连接代码，按回车

在窗口中粘贴你收到的完整设备连接代码，按 Enter 并等待执行完成。

命令提示符 · 管理员操作示意

执行后，打开 Tailscale 确认连接状态。这里展示的是操作示意，请使用实际收到的代码。其他系统请按管理员提供的对应方式接入。
