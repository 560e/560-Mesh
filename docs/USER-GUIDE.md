# 560-Mesh 使用教程

## 先分清两种用户

管理员账号用于登录网页控制台。Headscale用户用于归属组网设备与访问策略，两者不是同一概念；控制台管理权限不因创建一个Headscale用户自动产生。

## 添加设备

1. 安装 [Tailscale 官方客户端](https://tailscale.com/download)。
2. 管理台“用户与互通”中准备设备归属用户。
3. 到“设备接入”新建配置，填写名称、设备所有者，选择自动生成密钥。
4. 按需选择客户端选项，保存后复制完整命令。
5. Windows在开始菜单搜索cmd，以管理员身份运行，粘贴命令并按Enter；其他系统使用对应终端和权限。
6. 回到设备工作台确认设备出现，再进行实际连通测试。

完整命令包含认证密钥，只应发给可信设备。不要放进Issue、截图、共享文档或公开脚本。

## 密钥与选项记忆

自动创建的预认证密钥默认可重复使用、999天、非临时节点。可在配置中调整有效期。过长有效期与复用意味着需要更谨慎保管。
平台保存其创建的完整密钥原文供授权管理员查看；从其他工具创建、平台未保存原文的密钥不能凭空恢复。
密钥支持删除；删除密钥不等于注销已经加入的设备，设备退网另在设备工作台操作。

浏览器按服务器与管理员记住上次成功创建时的选项。命令名称、设备名称、选中的密钥和密钥内容不会自动带入；失败创建和编辑旧配置不覆盖创建记忆。
“恢复默认”回到默认选项。默认不接受DNS；开启空白子网路由列表会建议192.168.0.0/24，请改成实际网络。

## 路由与出口节点

- 发布子网路由：填写网络CIDR，逗号分隔；只发布你有权管理的网络。
- 接受子网路由：允许客户端使用其他设备已发布且获批的路由。
- 作为出口节点：向网络宣告本机可供出口使用。
- 使用出口节点：填写已可用的出口设备IP/名称，与“作为出口节点”互斥。

生成命令不自动配置系统转发、路由批准或ACL；这些步骤仍需按客户端系统与控制台提示完成。
若客户端提示tailscale up必须包含全部非默认选项，保留其提示中的旧选项，或明确使用“重置未指定偏好”。重置会清除未列出的旧偏好。
切换控制服务器且提示需要重新登录时，勾选“强制重新认证”。该选项会重新认证当前设备。

## 用户隔离与互通

符合条件的默认全允许策略会初始化为用户隔离，同用户设备互通。自定义ACL、文件策略和明确保存的管理选择不会被静默替换。
若选择若干用户参与互通，这些用户的设备可以相互访问；仍要结合其他策略、设备状态和系统防火墙验证。
保留现有自定义策略的安装，应按界面提供的迁移/冲突提示处理，不要直接覆盖重要ACL。标签设备的归属与权限遵循Headscale ACL语义。

## DERP与连接方式

进入“系统设置 → DERP中继”，可使用官方、已部署自建服务，或两者一起使用。最多16个自建服务，HTTPS端口默认443；每个地址独立配置可选STUN端口。
例如https://derp.example.com或https://derp.example.com:8443。需要实际可用的DERP服务；普通网站HTTPS反代不自动等于DERP，反代需支持相应协议升级。
检测检查DNS、TLS和DERP握手；不代表所有客户端网络的STUN或实际中继流量都可达。
保存后应用受控配置，失败时回退。客户端通常优先直连，无法直连才选择中继；使用tailscale status、ping等客户端诊断确认具体链路。

## DNS与首页

MagicDNS关闭时可使用组网IP，base_domain可空。启用时设置独立内部域名；网页保存的DNS覆盖与基础配置关系见配置参考。
“站点外观”设置公开首页左上角与浏览器标题，保存后刷新生效。首页默认“连接助手”，不显示管理入口和真实连接命令。
客户端链接指向官方稳定版别名或平台页，跟随官方下载入口；不自动升级已经安装的客户端。
